# AIGES editorial portfolio landing

React + Vite + React Router + Framer Motion.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Project content lives in `src/data.js`.
Main layout and case template live in `src/App.jsx`.
All styling lives in `src/styles.css`.

## Routes

- `/`
- `/projects/ma-store`
- `/projects/pr-platform`
- `/projects/dar-group`
- `/projects/aiges-lab`

`vercel.json` is included so direct project routes work on Vercel.
